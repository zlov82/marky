# Marky

Приложение для macOS в строке меню: включаешь режим, рисуешь поверх экрана, снимаешь скриншот штатными средствами (`⇧⌘3/4/5`). Подробности в [SPEC.md](SPEC.md).

## Сборка и запуск

Нужны macOS 26+ и Swift (хватает Command Line Tools, Xcode не нужен).

```sh
./build.sh
open build/Marky.app
```

Для автозапуска при входе лучше положить собранное приложение в `/Applications`:

```sh
cp -R build/Marky.app /Applications/
```

Подпись локальная (ad-hoc), только для себя. Если macOS попросит подтвердить пункт «Marky» в «Системные настройки → Основные → Объекты входа», подтвердите.

## Горячие клавиши

| Действие | Клавиша |
|---|---|
| Включить / выключить режим | `⌃⌥D` (настраивается) |
| Свободная линия / стрелка / прямоугольник / окружность | `F` / `A` / `R` / `C` |
| Красный / жёлтый / синий / зелёный | `1` / `2` / `3` / `4` |
| Тоньше / толще (1–20) | `[` / `]` |
| Прямая линия, квадрат, круг | удерживать `⇧` |
| Отменить последнюю фигуру | `⌘Z` |
| Очистить всё | `⌫` |
| Выйти (рисунок стирается) | `Esc` |

Все клавиши, кроме `Esc`, `⌘Z`, `⌫` и `⇧`, меняются в меню трея: «Настройки…». «Сбросить по умолчанию» возвращает таблицу выше.

## Структура

- `Sources/Marky/AppDelegate.swift` — иконка и меню в трее, автозапуск
- `Sources/Marky/HotKey.swift` — глобальный хоткей (Carbon)
- `Sources/Marky/OverlayWindow.swift` — прозрачное окно на экране с курсором
- `Sources/Marky/OverlayView.swift` — ввод и отрисовка
- `Sources/Marky/Shape.swift` — фигуры
- `Sources/Marky/Bindings.swift` — шорткаты, проверки и сохранение
- `Sources/Marky/SettingsWindow.swift` — окно настройки шорткатов
- `Sources/Marky/Settings.swift` — палитра и сохраняемые настройки
